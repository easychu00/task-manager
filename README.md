# 智能任务管理系统

基于 **Node.js (Express) + Supabase** 的简洁任务管理应用，中文界面。

## 功能特性

- 输入框 + 优先级下拉（高/中/低）添加任务
- 任务列表显示标题、优先级标签、完成状态
- 每条任务支持「完成/未完成」切换按钮
- 删除任务按钮
- 按优先级筛选（全部/高/中/低）
- 任务按创建时间倒序显示（最新在最上面）
- 已完成任务自动加删除线、颜色变淡
- 数据存储在 Supabase 云端数据库，刷新不丢失

## 快速开始

### 1. 创建 Supabase 项目

前往 [supabase.com](https://supabase.com) 注册并新建一个项目（Region 选 Singapore）。

### 2. 建 tasks 数据表

在 Supabase 控制台 → SQL Editor → New query，粘贴以下 SQL 并点 Run：

```sql
create table if not exists tasks (
  id bigint generated by default as identity primary key,
  title text not null,
  priority text not null default '中' check (priority in ('高', '中', '低')),
  completed boolean not null default false,
  created_at timestamptz not null default now()
);
```

### 3. 打开 RLS 访问策略

继续在 SQL Editor 新建查询，粘贴并 Run（否则外部写不进数据）：

```sql
alter table tasks enable row level security;

create policy "Allow anon read" on tasks for select using (true);
create policy "Allow anon insert" on tasks for insert with check (true);
create policy "Allow anon update" on tasks for update using (true) with check (true);
create policy "Allow anon delete" on tasks for delete using (true);
```

### 4. 获取连接凭据

左侧点齿轮图标（Project Settings）→ API Keys，复制：

| 凭据 | 示例 |
|------|------|
| Project URL | `https://xxxxxxxx.supabase.co` |
| Publishable key | `sb_publishable_xxxxxxxx` |

### 5. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的 Supabase 凭证：

```env
SUPABASE_URL=https://你的项目ID.supabase.co
SUPABASE_ANON_KEY=sb_publishable_你的key
PORT=3000
```

> 注意：认准以 `sb_publishable_` 开头的 key，不要用 `sb_secret_` 开头的保密密钥。

### 6. 安装依赖并启动

```bash
cd task-manager
npm install
npm start
```

打开浏览器访问 **http://localhost:3000** 即可使用。

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tasks?priority=高` | 获取任务列表（可选按优先级筛选） |
| POST | `/api/tasks` | 添加任务 `{title, priority}` |
| PATCH | `/api/tasks/:id/toggle` | 切换完成状态 |
| DELETE | `/api/tasks/:id` | 删除任务 |

## 部署到 Vercel

在 Vercel 导入 GitHub 仓库后，Environment Variables 中添加：

| Name | Value |
|------|-------|
| SUPABASE_URL | `https://你的项目ID.supabase.co` |
| SUPABASE_ANON_KEY | `sb_publishable_你的key` |
| NODE_ENV | `production` |
| CLIENT_BASE_PATH | `/` |
